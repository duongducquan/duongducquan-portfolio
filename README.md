## 👋 Về mình – Dương Đức Quân

Xin chào, mình là **Dương Đức Quân**, trên mạng dùng tên **duongducquan** và **DuongDucQuan**.

- 💻 Sinh viên và lập trình viên **Full Stack Web**, tự dựng giao diện, viết API, thiết kế database rồi đưa website lên hosting.
- 🌐 Làm việc với **React, Node.js, PHP, MySQL**, dùng **Socket.IO** cho chức năng realtime.
- 🗺️ Đang nghiên cứu **GIS** (OpenStreetMap, Nominatim, Overpass API) trong quá trình thực tập.
- 🔍 Học và áp dụng **SEO On-page** cho các website cá nhân.
- 🤖 Dùng AI (Claude Code, Gemini, Groq API) để học nhanh và rà lỗi, còn kiến trúc và logic mình tự quyết định.
- 📍 Ở TP. Hồ Chí Minh, Việt Nam.
- 🏢 Làm việc cùng MidSortWare / MID Việt Nam.
- 📫 Liên hệ qua Facebook, LinkedIn hoặc GitHub ở mục liên kết bên dưới.

> **Lưu ý trung thực:** kiến trúc phần mềm, Docker, CI/CD và triển khai nâng cao là kiến thức mình đang tìm hiểu thêm, chưa phải đã làm thành thạo trong dự án thực tế.

### Cơ sở dữ liệu

- **MySQL:** SQL, JOIN, CRUD, cơ sở dữ liệu quan hệ, quản lý bằng phpMyAdmin.
- **MongoDB:** cơ sở dữ liệu NoSQL.
- **Connection Pool:** quản lý kết nối database.
- **Database Design:** thiết kế bảng, quan hệ, khóa chính, khóa ngoại.
- **JSON:** định dạng trao đổi dữ liệu giữa frontend và backend.

### API và giao tiếp thời gian thực

- HTTP: GET, POST, PUT, PATCH, DELETE.
- REST API và JSON, Authentication, Authorization.
- WebSocket và Socket.IO: chat realtime, room, event, emit, broadcast.
- Đồng bộ dữ liệu giữa điện thoại và máy tính.
- Tài liệu API với Swagger UI, OpenAPI; kiểm thử bằng Postman.

| Công nghệ | Nội dung |

## 🔍 SEO On-page

SEO On-page là phần tối ưu ngay trên website để Google hiểu nội dung. Với các trang của **Dương Đức Quân (DuongDucQuan)**, mình áp dụng:

- Thẻ **title** và **meta description** chứa từ khóa chính.
- Một thẻ **H1** cho mỗi trang, các mục con dùng H2, H3 đúng thứ bậc.
- **HTML ngữ nghĩa:** header, nav, main, article, section, footer.
- **Canonical URL** để tránh trùng nội dung.
- **Open Graph và Twitter Card** để chia sẻ đẹp trên mạng xã hội.
- **Dữ liệu có cấu trúc JSON-LD** (Person, Article, FAQPage).
- Thuộc tính **alt** cho hình ảnh, ảnh tối ưu dung lượng.
- **Liên kết nội bộ** bằng mục lục và anchor text rõ nghĩa.
- **sitemap.xml, robots.txt**, xác minh bằng Google Search Console, theo dõi bằng Google Analytics.
- **Responsive và tải nhanh** cho cả điện thoại.
